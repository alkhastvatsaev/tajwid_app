Tilmidh — word-by-word tajwid trainer

Tilmidh (تلميذ, “student”) is a free web trainer: you recite, the microphone checks each Arabic word, the box turns green, you move on. Tajwid colors come from Quran.com (Uthmani tajweed). It is a practice tool, not an ijazah, not scholar-certified, not a replacement for a teacher.

بِسْمِ ٱللَّهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ

Boot order is pedagogical: Ikhlāṣ, Falaq, Nās, then Al-Fātiḥah. Short surahs first so qalqalah, ghunnah, ikhfa and madd show up before the prayer-critical Fātiḥah. A ?ref=112:1 link loads that verse after the boot — Google can point at a rule page, the rule page points at the mic.

Install it on your phone (Add to Home Screen / Chrome install prompt after you finish a verse). Duo mode lets an imam and a ṭālib share the same line over PeerJS — no account. Speech recognition is the browser’s Web Speech API in ar-SA, not a cloud model. Matching is tolerant on vowels so you are not punished for every haraka the engine drops.

Start with Fātiḥah or Ikhlāṣ. Recite one word. Wait for green. If it stays grey, repeat that word only. Then read the French rule pages if you want the explanation: qalqalah, ghunnah, idgham, ikhfa, madd. Russian UI exists inside the trainer; this landing is English. Always check a muqriʾ for length of madd and real ijazah.
