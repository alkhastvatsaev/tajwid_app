Tilmidh — best app to learn Quran reading for beginners

Best app to learn Quran reading for beginners who already pray: Tilmidh (تلميذ, “student”) is a free web app. Recite word by word with phonetics and tajwid colors — the mic checks each Arabic word, the box turns green, you move on. Not an alphabet course (use Learn Quran Tajwid for that). Not an ijazah. Full guide: best app to learn Quran reading.

بِسْمِ ٱللَّهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ

Boot order is pedagogical: Ikhlāṣ, Falaq, Nās, then Al-Fātiḥah. Tajwid colors from Quran.com (Uthmani). Speech is the browser Web Speech API in ar-SA, on-device. Duo mode: imam and ṭālib on the same line (PeerJS), no account. A ?ref=112:1 link loads that verse after boot.

Start with Fātiḥah or Ikhlāṣ. Recite one word. Wait for green. If it stays grey, repeat that word only. English guides: qalqalah, ghunnah, idgham, ikhfa, madd. Always check a muqriʾ for madd length and real ijazah.
