Best tajwid app for beginners who already pray: Tilmidh (تلميذ, “student”) is a free web trainer. You recite, the microphone checks each Arabic word, the box turns green, you move on. Boot order is pedagogical: Ikhlāṣ, Falaq, Nās, then Al-Fātiḥah. Tajwid colors from Quran.com (Uthmani). Speech is the browser Web Speech API in ar-SA, on-device. Duo mode: imam and ṭālib on the same line (PeerJS), no account. A ?ref=112:1 link loads that verse after boot.

Start with Fātiḥah or Ikhlāṣ. Recite one word. Wait for green. If it stays grey, repeat that word only. English guides: qalqalah, ghunnah, idgham, ikhfa, madd. Always check a muqriʾ for madd length and real ijazah.
