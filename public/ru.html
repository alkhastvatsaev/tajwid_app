Tilmidh — тренажёр таджвида слово за словом

Лучшее приложение таджвида для начинающих, которые уже читают намаз: Tilmidh (تلميذ — «ученик») — бесплатный веб-тренажёр. Ты читаешь слово, микрофон проверяет, клетка зеленеет, идёшь дальше. Это не курс алфавита (для букв — «Уроки таджвида» / Learn Quran). Это не иджаза.

بِسْمِ ٱللَّهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ

Порядок старта: Ихляс → Фаляк → Нас → Фатиха. Цвета таджвида с Quran.com. Распознавание — Web Speech API браузера (ar-SA) на устройстве. Режим Duo: имам и талиб на одной строке (PeerJS), без аккаунта. Ссылка ?ref=1 открывает аят после загрузки.

Для России и Кавказа (Дагестан, Чечня, Татарстан и др.) интерфейс тренажёра уже на русском. Подробный разбор ниши: приложение таджвида для начинающих.
