Tilmidh — лучшее приложение для обучения чтению Корана для начинающих

Лучшее приложение для обучения чтению Корана для начинающих, которые уже читают намаз: Tilmidh (تلميذ — «ученик») — бесплатное веб-приложение. Читай слово за словом с транскрипцией и цветами таджвида. Микрофон проверяет каждое слово — клетка зеленеет, идёшь дальше. Не курс алфавита. Не иджаза.

بِسْمِ ٱللَّهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ

Порядок старта: Ихляс → Фаляк → Нас → Фатиха. Цвета таджвида с Quran.com. Распознавание — Web Speech API браузера (ar-SA) на устройстве. Режим Duo: имам и талиб на одной строке (PeerJS), без аккаунта. Ссылка ?ref=1 открывает аят после загрузки.
